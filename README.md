# yuxuan255.github.io

个人技术博客,基于 Astro + Markdown + 原生 CSS 构建,部署于 GitHub Pages。

## 常用命令

```bash
npm run dev        # 本地开发
npm run verify     # 完整验证:格式 → 内容 → astro check → build → 链接
npm run format     # 格式化代码
```
